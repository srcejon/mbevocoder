# Test corpus sources and licences

The corpus itself is not stored in this repository. `tools/corpus/fetch.py` downloads the
sources listed in `manifest.json` into `corpus/raw/`, and `tools/corpus/prepare.py` builds the
test set (8 kHz, 16-bit mono, active speech level -26 dBov) into `testdata/corpus/` together
with `testdata/corpus/INDEX.json` recording, per file, its origin, speaker sex, duration and the
processing applied. The prepared set is what gets bundled into the `mbevocoder-testdata` release.

| Source | Files used | Licence | Attribution |

LibriSpeech is CC BY 4.0 with the attribution above; CMU ARCTIC is under its licence (Copyright
Carnegie Mellon University, Language Technologies Institute). None of these speakers is in the
70-file corpus.

Not used, and why:
- TIMIT: LDC licence, not redistributable.
- ITU-T P.501 speech: licence limits use to conformance testing and forbids redistribution outside that scope.
- Mozilla Common Voice: download now requires an account; may be added later for non-English material.
- DVSI sample files: no stated licence.

Processing: resampling with ffmpeg's soxr resampler (`-af aresample=resampler=soxr:precision=28`),
DC removal, then gain to -26 dBov active speech level using a P.56-style activity estimate
(frames within 40 dB of the loudest 20 ms frame count as active). No compression or limiting;
files that would clip are scaled down and flagged in INDEX.json.
